# Natural Grounded Rewriter

A portable LLM writing skill for transforming generic, mechanical,
or awkward prose into purposeful, grounded, coherent content.

## Capabilities

- Natural rewriting and light editing.
- Voice and genre adaptation.
- Factual and semantic preservation.
- Structured-content and multilingual safeguards.
- Context-sensitive diagnosis and selective revision.

## Version

## Usage

For skill-compatible applications, install the complete
natural-grounded-rewriter folder.

See HOW-TO-USE.md for details.
